# Local source archive — 2026-10-16

Preserves previously ignored/untracked Rust Star experimental source, scripts and notes before user-authorized removal of the local checkout. Paths and SHA-256 hashes are in manifest.json. Historical and rejected experiments are not promoted to production or newly validated. Oracle worktree revisions and local patches are retained separately.

Large raw tensor captures, models, compiled tools and caches are intentionally not archived. Published reports remain historical evidence; rerunning checks requiring deleted raw artifacts will require regeneration. No new inference, benchmark or product release is claimed by this archival change.
